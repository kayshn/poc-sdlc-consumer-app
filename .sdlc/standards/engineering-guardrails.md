# Engineering guardrails

Invariant — part of the AI-native SDLC standard, pulled by tag. Do not edit this file in a
consumer repo: a local edit is drift and `make template-check` will fail on it. Project-specific
rules go in `.sdlc/standards/project-guardrails.md`, which is yours.

These are conditions on any change you propose, not advice. A pull request that breaks one is
rejected on that ground alone. Cite the guardrail by id when one of them shapes what you did.

## G1 — Evidence, not assertion
Report a command as run only if you paste its output. Name every check you could not run, and
why. "Tests pass" without the run is a claim, and a claim is not a check.

## G2 — Never silence a check
Do not add a suppression (`# noqa`, `# type: ignore`, `eslint-disable`, `@SuppressWarnings`),
loosen a threshold, or delete an assertion in order to turn something green. Fix the cause. If
the check itself is wrong, argue that in the PR and leave it red.

## G3 — No new runtime dependency without a named reason
Anything added to the shipped artefact needs one line in `.sdlc/plans/<slug>.md` saying what it
does and what it replaces. Dev-only tooling is exempt.

## G4 — Partial is a status, not a failure
If a plan step is half done, mark it `partial` and name what is still open. Never mark a step
complete on the strength of the part that worked.

## G5 — User input never reaches a log, an error message, or an SDLC artefact
Echoing it back is how an instruction hidden in data becomes an instruction you follow later.
Refer to records by id.

## G6 — Architecture changes show up in the diagram
If a change adds, removes or re-points a deployable unit, a datastore, an external service or a
trust boundary, the same change amends the high-level diagram named by `stages.design.diagram` in
`.sdlc/flow.yaml`, and the spec carries the amended view under `## High-level design` with one line
saying what moved. A spec that leaves the architecture alone writes `No architectural change.`
there, and why. Deciding this rule does not apply is a claim like any other: make it in writing.
