# The received layer: the part of the AI-native SDLC template that a consuming project gets rather
# than owns. `make manifest` hashes exactly these paths into .sdlc/MANIFEST.sha256, and
# `make template-check` fails if any of them has drifted locally.
#
# Everything NOT listed here is yours to change: your Makefile targets, CLAUDE.md, flow.yaml,
# bands.json, protected-paths.txt, .sdlc/architecture/, .sdlc/standards/project-guardrails.md,
# .sdlc/REVIEW.local.md, .claude/settings.json, the secure-api-review skill and the deploy scripts.
#
# This file lists itself, so that removing something from the standard is a visible edit here.
.sdlc/invariant.txt

# How a release changes the shape of a project: relocating a path the project owns, or taking over
# a file it used to own. Received rather than owned, because the consumer is the one it is done to.
#
# This file, the manifest and .sdlc/TEMPLATE_VERSION all stay at .sdlc/ and can never move: an
# upgrade is run by the copy of sdlc_update.sh installed *before* it, and that copy reads all three
# from the incoming archive at these exact paths.
.sdlc/MIGRATIONS

# Everything the loop needs that is not pinned to a path by another tool. A directory entry is
# find-expanded, which was once a hazard — a consumer's own file could be swept into the manifest.
# It is safe here precisely because this directory is exclusively the standard's: a file appearing
# in it that the standard did not ship is itself the signal, not an accident waiting to happen.
.sdlc/upstream

# Pinned to .claude/ by Claude Code, which discovers them by convention rather than by a configured
# path, so they stay there and are listed one by one. The bodies are the standard's; what they do
# for a given project is reached through a seam: format-on-edit.sh calls `make format-file`,
# verifier.md calls `make verify`, and protect-paths.sh reads .sdlc/protected-paths.txt.
.claude/hooks/_lib.sh
.claude/hooks/format-on-edit.sh
.claude/hooks/production-gate.sh
.claude/hooks/protect-paths.sh
.claude/agents/verifier.md
.claude/skills/write-intent/SKILL.md
.claude/skills/write-spec/SKILL.md
